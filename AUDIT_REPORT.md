## 🚨 КРИТИЧЕСКИЕ ПРОБЛЕМЫ (Приоритет 1)

### 1. ВИЗУАЛЬНАЯ ЧАСТЬ — ПРОВАЛ ДЛЯ KICKSTARTER

**Проблема:** Интерфейс использует примитивные прямоугольники без текстур
- `NanoVGManager.java` — рисует только цветные прямоугольники
- `ProgressionWindow.java` — карточки характеристик выглядят как прототип
- `EquipmentWindow.java` — слоты экипировки без стилизации под Tarkov/STALZONE
- `ContainerWindow.java` — инвентарь без разделения на ячейки, нет фона

**Вопрос для выбора решения:**
> **Как будем делать визуально дорого?**
> 
> **A)** Использовать бесплатные ассеты из открытых источников (OpenGameArt, itch.io free section)
> **B)** Сгенерировать текстуры через AI (Stable Diffusion с prompt "tarkov style UI texture")
> **C)** Нарисовать минималистичный стиль самостоятельно в Figma/Photoshop (требуется дизайнер)
> **D)** Оставить программную генерацию но добавить градиенты, тени, анимации (быстро, но менее эффектно)

**Рекомендация:** Комбинация B+C — AI для базовых текстур + ручная доработка ключевых элементов

---

### 2. ОТСУТСТВИЕ СИСТЕМЫ РЕДКОСТИ ПРЕДМЕТОВ

**Проблема:** В коде нет упоминаний о rarity (редкости)
- Нет цветовой кодировки предметов (Common/Rare/Epic/Legendary)
- Нет визуального отличия между обычным хламом и ценным лутом
- Инвесторы не увидят "зависимость от прогресса"

**Вопрос для выбора решения:**
> **Какая система редкости нужна?**
> 
> **A)** Классическая: Common (серый), Uncommon (зеленый), Rare (синий), Epic (фиолетовый), Legendary (оранжевый)
> **B)** Сталкерская: Обычный, Артефакт, Уникальный, Легендарный
> **C)** Tarkov-стиль: Без явной редкости, но с разной ценой и иконками
> **D)** Гибридная: Цветная рамка + иконка качества + цена

**Рекомендация:** Вариант D — дает максимальную визуальную отдачу при минимальных затратах

---

### 3. НЕТ ЗВУКОВЫХ ЭФФЕКТОВ

**Проблема:** Полное отсутствие звуков интерфейса
- Нет кликов по кнопкам
- Нет звука получения уровня
- Нет звука экипировки предмета
- Нет звука открытия контейнеров

**Вопрос для выбора решения:**
> **Откуда брать звуки?**
> 
> **A)** Бесплатные библиотеки (Freesound.org, OpenGameArt audio)
> **B)** Сгенерировать через AI (ElevenLabs для UI sounds)
> **C)** Использовать звуки Minecraft с питчем
> **D)** Записать самому с модификацией

**Рекомендация:** Вариант A + C — быстро и бесплатно

---

### 4. БАЛАНС ПРОКАЧКИ НЕ ПОДХОДИТ ДЛЯ ДЕМКИ

**Проблема:** Текущие значения XP в `ProgressionComponent.java`:
```java
private static final long[] XP_MILESTONES = {
    0L, 3_000_000L, 25_000_000L, 120_000_000L, ...
};
```
- Для демо нужно достигать 10 уровня за 10-15 минут
- Сейчас это займет часы геймплея
- Инвесторы не увидят прогресс за время презентации

**Вопрос для выбора решения:**
> **Как настроить баланс для демо?**
> 
> **A)** Отдельный конфиг `demo_balance.json` с уменьшенными значениями
> **B)** Команда `/demo_setup` которая ставит нужный уровень и предметы
> **C)** Автоматическое определение режима демо по флагу
> **D)** Ручная настройка через команды админа во время записи

**Рекомендация:** Вариант A+B — гибко и профессионально

### 5. ИНВЕНТАРЬ БЕЗ КОНТЕЙНЕРОВ РАЗНЫХ ТИПОВ

- Нет системы слотов разной формы (как в Tarkov)
- Нет визуального отличия контейнеров

**Вопрос для выбора решения:**
> **Как реализовать контейнеры?**
> 
> **A)** Простая сетка с разным количеством слотов (быстро)
> **B)** Grid-система с ячейками 1x1, 1x2, 2x2, 2x3 (как в Tarkov)
> **C)** Упрощенная версия — только размер имеет значение
> **D)** Отложить на пост-Kickstarter

**Рекомендация:** Вариант A для демо, B — цель для полной версии

### 6. ОТСУТСТВИЕ ЧАСТИЦ И ВИЗУАЛЬНЫХ ЭФФЕКТОВ

**Проблема:** Нет файлов с частицами
- LevelUpHudRenderer показывает только текст
- Нет искр, свечения, взрывов при повышении уровня
- Нет эффектов при экипировке легендарных предметов

**Вопрос для выбора решения:**
> **Как добавить эффекты?**
> 
> **A)** Использовать встроенные частицы Minecraft
> **B)** Создать простые спрайтовые эффекты
> **C)** Интегрировать систему частиц через GeckoLib
> **D)** Минималистичные эффекты через NanoVG (свечение, вспышки)

**Рекомендация:** Вариант A+D — быстро и эффектно

### 7. ТОЛЬКО ОДИН ЯЗЫК (EN_US)

**Проблема:** В `lang/en_us.json` только английский

- Русскоязычные бэкеры не поймут интерфейс
- Тексты в коде жестко закодированы на русском (`"УРОВЕНЬ ПОВЫШЕН"`)

**Вопрос для выбора решения:**
> **Как организовать локализацию?**
> 
> **A)** Добавить ru_ru.json и перевести всё
> **B)** Использовать только русский для старта (целевая аудитория)
> **C)** Сделать переключатель языков в меню
> **D)** Отложить локализацию

**Рекомендация:** Вариант B для демо, A+C для релиза
